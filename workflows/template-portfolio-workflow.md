# Template Portfolio Workflow

## Outcome

Five implementation-ready product concepts with a deliberate commercial portfolio, including at least one admin template.

## Steps

### 1. Generate candidates

Create 8–12 concepts. For each, state buyer, use case, likely pages, signature visual opportunity, Astro suitability, and backend dependency risk.

### 2. Score candidates

Score 1–5 for:

- Buyer clarity.
- Demand breadth.
- Astro fit.
- Visual differentiation.
- Content demonstrability.
- Customization value.
- Implementation risk, reverse-scored.
- Complementarity with the bundle.

Record the score and one-sentence rationale.

### 3. Select the collection

Choose five concepts. At least one must be an admin/dashboard. Avoid selecting five marketing sites for adjacent SaaS niches.

A balanced default is:

- Operations/admin.
- B2B SaaS.
- Studio/portfolio.
- Editorial/knowledge.
- Catalog/commerce/hospitality/service.

### 4. Name and position products

Create original names after checking for obvious collision risk. Use descriptive marketplace subtitles even when the brand name is abstract.

For each, write:

- One-sentence promise.
- Intended buyer.
- Primary job-to-be-done.
- Key purchase reasons.
- Customization story.
- Static-demo boundaries.

### 5. Write briefs

Use the template brief schema. Define route inventory, content model, signature compositions, interaction scope, design expression, responsive behavior, and anti-overlap constraints.

### 6. Build matrices

Create:

- Route matrix: routes by product and purpose.
- Differentiation matrix: intended differences across twelve dimensions.
- Shared-primitives matrix: what may be shared and what must remain app-specific.

### 7. Review feasibility

Reject or revise any concept whose strongest selling point cannot be credibly demonstrated in a static Astro template.

## Exit criteria

- Exactly five selected products.
- Admin requirement satisfied.
- Every brief is implementation-ready.
- Initial pairwise differentiation is projected to pass 16/24.
- The collection has a clear bundle narrative.
