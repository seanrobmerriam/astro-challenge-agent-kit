# Collection Quality Gates

This summary is intentionally redundant with the workflows so agents and reviewers can run a fast release check.

## Per-template blockers

- Clean installation or production build fails.
- Required route or state is missing.
- Starter branding, lorem ipsum, or broken internal link remains.
- Keyboard access, visible focus, form labeling, or critical contrast fails.
- Mobile navigation or the primary mobile task is unusable.
- Bundled dependency, font, image, or other asset has unresolved resale rights.
- Buyer-facing installation instructions do not work from a clean archive.
- Package contains secrets, real credentials, analytics identifiers, caches, or installed dependencies.

## Collection blockers

- Fewer than five templates.
- No admin template.
- `design-system` is not a single-page rendered reference.
- Any template pair scores below 16/24 for differentiation.
- High-level product components are shared in a way that makes products visibly interchangeable.
- Verification report omits build, route, accessibility, responsive, performance, licensing, or differentiation results.
