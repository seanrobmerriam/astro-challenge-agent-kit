# Design System Reference

A single-page Astro reference for the template collection's custom design system. It demonstrates foundations, components, application-density patterns, accessibility rules, and five template expression modes.

## Commands

```bash
npm install
npm run dev
npm run build
```

The production agent should copy or merge this implementation into the `design-system` app derived from the user's `base-template/`. Preserve the base template's justified infrastructure and package-manager conventions.

## Customization

- Core tokens: `src/styles/global.css`
- Page content and examples: `src/pages/index.astro`
- Document shell and metadata: `src/layouts/BaseLayout.astro`
